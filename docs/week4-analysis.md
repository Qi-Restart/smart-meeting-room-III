# 第4周数据分析与基线预测结果

## 1. 数据来源

本周分析使用第3周数据清洗后生成的：

`data/processed/clean_sensor_data.csv`

清洗后共有300条记录，其中295条具有有效的 `occupancy` 数据，可用于会议室占用情况分析。

当前数据属于教学测试数据，数据来源标记为 `mock`。

## 2. 数据分析结果

### 2.1 各时段会议室占用率

统计口径：

某小时占用率 = 该小时 `occupancy = 1` 的有效采样数 ÷ 该小时有效采样总数。

分析结果：

14:00—15:00为本数据集中最繁忙的时间段，占用率为 **68.97%**。

对应图表：

`results/01_hourly_occupancy.png`

### 2.2 不同会议室平均利用率

统计口径：

会议室利用率 = 该会议室 `occupancy = 1` 的有效采样数 ÷ 该会议室有效采样总数。

分析结果：

R01会议室平均利用率最高，为 **54.90%**。

对应图表：

`results/02_room_utilization.png`

### 2.3 人员状态与设备使用情况

统计口径：

分别统计有人和无人状态下灯光、投影仪和空调处于开启或运行状态的采样比例。

分析结果：

无人状态下：

- 灯光开启比例为 **19.14%**
- 投影仪开启比例为 **0.62%**
- 空调运行比例为 **0.62%**

有人状态下：

- 灯光开启比例为 **100.00%**
- 投影仪开启比例为 **42.11%**
- 空调运行比例为 **100.00%**

结果表明，有人状态下灯光和空调的使用比例明显提高；同时无人状态下仍存在19.14%的灯光开启记录，说明当前系统存在一定的无效设备使用现象，可作为后续节能控制功能的改进依据。

对应图表：

`results/03_device_usage.png`

## 3. 基线预测方法

本周建立会议室占用状态阈值基线。

预测规则：

历史同一会议室、同一小时的平均占用率大于0.5，则预测该时段有人；否则预测无人。

## 4. 数据切分

按照时间进行训练数据和测试数据切分。

历史数据：

2026-09-07 至 2026-09-10，共 **236条** 有效记录。

测试数据：

2026-09-11，共 **59条** 有效记录。

采用按时间切分的方法，保证测试数据不参与历史占用率计算。

## 5. 基线预测结果

测试样本量：**59**

总体预测准确率：**61.02%**

实际有人样本：

- 共31条
- 正确预测15条
- 正确率约48.39%

实际无人样本：

- 共28条
- 正确预测21条
- 正确率75.00%

预测明细保存于：

`results/baseline_predictions.csv`

## 6. 结果说明

当前基线模型仅使用历史会议室和小时占用率进行判断，模型结构简单，可解释性较强，并且能够通过：

`python scripts/baseline_model.py`

重复生成预测结果。

当前61.02%的准确率作为后续算法改进的基准，不代表最终预测模型性能。后续可结合预约信息、工作日信息、环境状态和更长时间范围的历史数据进一步提高预测效果。
