# 源代码目录说明

## README.md

项目说明文件，介绍系统功能、运行方式和项目结构。

## requirements.txt

Python 依赖库列表，用于记录后端运行所需的第三方库。

## run_backend.sh

后端启动脚本，用于进入项目目录、激活虚拟环境并运行后端程序。

## backend/sensor_server.py

树莓派后端主程序，负责读取温湿度、光照、烟雾、人体红外、超声波等传感器数据，控制舵机门禁，调用摄像头进行人脸录入和识别，并通过 WebSocket 向前端发送实时数据，同时提供摄像头视频流。

## frontend/smart_room.html

Web 前端主页面，负责显示三个可切换的 3D 会议室模型，展示实时传感器数据、历史图表、摄像头画面，并提供人脸录入、开启识别、停止识别、手动开门、灯光调节、投影仪调节和空调控制功能。

## face_dataset/

人脸录入样本保存目录。

## trainer/

人脸识别模型保存目录。
