# 人脸图像预处理算法说明

## 1. 算法模块说明

本项目在原有 Haar 人脸检测 + LBPH 人脸识别方案基础上，对人脸图像预处理环节进行自主实现和改进。

本环节的目标不是直接提高最终识别结果，而是先对摄像头采集的人脸图像进行规范化处理，尽量降低不同光照、图像尺寸和噪声对后续人脸检测与识别造成的影响。

本组将人脸预处理作为第5周自主实现的关键环节之一。

对应源代码：

`face_recognition/preprocess.py`

---

## 2. 输入与输出

### 输入

摄像头采集得到的原始彩色图像，或已经裁剪出的人脸区域图像。

输入图像格式为 OpenCV 读取的 BGR 图像。

### 输出

经过以下处理后的标准化灰度人脸图像：

```text
原始彩色图像
→ 灰度化
→ 尺寸统一
→ CLAHE光照增强
→ 高斯去噪
→ 标准化人脸图像
```

处理后的图像用于后续 Haar 人脸检测、LBPH 特征提取和识别。

---

## 3. 算法处理流程

### 3.1 灰度化

原始摄像头图像通常为 BGR 三通道彩色图像。

本项目首先使用 OpenCV 将图像转换为单通道灰度图像。

调用方式：

```python
cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
```

处理目的：

- 降低图像数据维度；
- 减少颜色信息对识别的干扰；
- 与 Haar 和 LBPH 的灰度图像处理方式保持一致；
- 降低后续计算量。

### 3.2 尺寸统一

不同采集距离和检测框大小可能导致人脸图像尺寸不一致。

本项目统一将人脸区域缩放为：

```text
200 × 200
```

调用方式：

```python
cv2.resize(face, (200, 200))
```

处理目的：

- 统一不同样本的输入尺寸；
- 避免图像尺寸差异影响后续特征计算；
- 方便训练数据和实时识别数据采用相同处理标准。

### 3.3 CLAHE光照增强

实际会议室环境中可能出现光照过强、过暗或局部亮度不均的情况。

本项目采用 CLAHE（限制对比度自适应直方图均衡化）对灰度图像进行局部对比度增强。

参数设置：

```python
clipLimit = 2.0
tileGridSize = (8, 8)
```

调用方式：

```python
clahe = cv2.createCLAHE(
    clipLimit=2.0,
    tileGridSize=(8, 8)
)

enhanced = clahe.apply(gray)
```

与普通全局直方图均衡化相比，CLAHE会将图像划分为多个局部区域分别进行增强，同时通过限制对比度避免局部噪声被过度放大。

处理目的：

- 改善暗光情况下的人脸纹理；
- 缓解局部光照不均；
- 增强眼睛、鼻部、嘴部等局部纹理信息；
- 提高后续LBPH特征的稳定性。

### 3.4 高斯去噪

摄像头采集过程中可能出现轻微的随机噪声。

本项目在光照增强后使用高斯滤波进行轻度去噪。

参数：

```text
核大小：3 × 3
sigmaX：0
```

调用方式：

```python
cv2.GaussianBlur(
    enhanced,
    (3, 3),
    0
)
```

采用较小的 `3 × 3` 滤波核，目的是减少细小噪声，同时尽量避免过度模糊人脸纹理。

处理目的：

- 减少摄像头图像中的随机噪声；
- 保留主要面部纹理；
- 为后续LBPH特征提取提供更加稳定的输入。

---

## 4. 核心参数

| 处理环节 | 参数 | 当前取值 | 作用 |
|---|---|---|---|
| 灰度化 | 转换方式 | `BGR2GRAY` | 彩色图像转单通道灰度图 |
| 尺寸统一 | 输出尺寸 | `200×200` | 保证所有人脸输入尺寸一致 |
| CLAHE | `clipLimit` | `2.0` | 限制局部对比度增强程度 |
| CLAHE | `tileGridSize` | `(8, 8)` | 将图像划分为局部区域 |
| 高斯去噪 | Kernel | `(3, 3)` | 减少轻微图像噪声 |
| 高斯去噪 | `sigmaX` | `0` | 由OpenCV根据核大小自动计算 |

## 5. 本组改进内容

原有系统主要依赖 Haar + LBPH 完成人脸检测和身份识别。

第5周在原方案基础上，对识别前的人脸图像增加统一预处理流程：

```text
灰度化
+
尺寸标准化
+
CLAHE局部光照增强
+
高斯去噪
```

本组没有直接将摄像头采集图像送入识别模型，而是自行编写统一预处理函数，对训练样本和实时识别人脸使用相同的处理规则。

该改进重点解决以下问题：

- 不同采集图像尺寸不统一；
- 室内不同位置光照存在变化；
- 暗光条件下局部人脸纹理不够明显；
- 摄像头图像存在轻微噪声；
- 训练样本与实时识别输入处理方式可能不一致。

---

## 6. 改进理由

LBPH主要利用图像局部纹理进行人脸特征描述。

如果同一对象在不同光照条件下的灰度分布差异过大，可能导致提取出的局部纹理特征产生变化。

因此，本项目在LBPH识别之前增加统一的图像预处理，通过光照增强、尺寸统一和轻度去噪，使训练阶段和识别阶段的人脸输入具有更一致的图像特征。

本次改进属于识别流程中的自主预处理环节，而不是直接调用一个完整人脸识别接口。
