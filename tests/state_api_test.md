# 会议室状态接口测试记录

> 文件名：`tests/state_api_test.md`  
> 项目：智能会议室管理系统 III  
> 测试对象：第三周模拟会议室状态接口  
> 数据来源：`mock`

## 1. 测试目的

验证第 3 周统一会议室状态接口是否能够按照约定返回规范 JSON，并能够正确处理正常会议室查询和非法会议室编号。

本次测试重点确认：

- 正常会议室状态可以成功查询；
- 返回字段符合统一状态对象约定；
- 非法会议室编号能够返回清楚的错误信息；
- 接口能够区分模拟数据和真实传感器数据；
- 模拟接口可以稳定重复运行。

## 2. 测试环境

- 操作系统：Windows
- Python：本机 Python 环境
- 接口程序：`mock/mock_state_api.py`
- 状态数据：`mock/state.json`
- 服务地址：`http://127.0.0.1:8000`
- 数据来源：`mock`
- 测试方式：浏览器访问接口

## 3. 接口启动

在项目根目录执行：

```powershell
python mock/mock_state_api.py
```

接口启动后显示：

```text

异常测试：http://127.0.0.1:8000/api/rooms/R99/state
数据来源：mock（教学模拟数据）
```

说明模拟接口启动成功。

## 4. 测试一：正常会议室状态查询

### 请求

```http
GET /api/rooms/R01/state
```

完整访问地址：

```text
http://127.0.0.1:8000/api/rooms/R01/state
```

### 预期结果

- 请求成功；
- 返回 `code = 200`；
- 返回 `message = "success"`；
- `data` 中包含 R01 的完整统一状态对象；
- `source = "mock"`。

### 实际结果

接口能够正常返回 R01 状态数据，返回结构符合接口约定。

示例响应：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "timestamp": "2026-10-10T10:30:00+08:00",
    "room_id": "R01",
    "occupancy": true,
    "temperature": 24.6,
    "humidity": 48.0,
    "door_status": "closed",
    "devices": {
      "light": "on",
      "projector": "off",
      "air_conditioner": "auto"
    },
    "source": "mock",
    "quality": "normal"
  }
}
```

### 测试结论

**通过。**

正常会议室编号可以返回规范 JSON，字段名称与 `state-object.md` 中的统一状态对象一致。

建议截图文件名：
