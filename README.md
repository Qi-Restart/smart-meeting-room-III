# 树莓派智能会议室管理系统

本项目基于树莓派实现智能会议室管理系统，系统通过多种传感器采集会议室环境数据，并通过 WebSocket 将实时数据发送到 Web 前端。前端使用 Three.js 构建三个不同风格的 3D 会议室模型，实现会议室状态可视化、设备联动控制、人脸识别门禁、摄像头画面显示和历史数据展示。

## 功能

1. 温湿度采集与空调联动；
2. 光照采集与灯光联动；
3. 烟雾浓度检测与报警提示；
4. PIR 人体红外检测与节能控制；
5. HC-SR04 超声波距离检测与门禁联动；
6. 树莓派摄像头实时画面显示；
7. 前端录入人脸并进行人脸识别；
8. 识别成功后舵机开门，前端 3D 门同步打开；
9. 三个不同风格会议室模型切换展示；
10. 前端手动控制灯光、投影仪和空调；
11. 温度、湿度、光照、烟雾历史图表展示。
