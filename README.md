# 树莓派智能会议室管理系统（综 III）

> 进阶式挑战性综合项目 III  
> 项目仓库：`smart-meeting-room-III`

## 1. 项目简介

本项目是在综合项目 II“树莓派智能会议室管理系统”基础上继续开发的第三阶段项目。

综合项目 II 已完成树莓派端环境感知、摄像头采集、设备控制、Web 管理页面、3D 会议室场景以及基础人脸识别与门禁联动等功能。综合项目 III 的工作重点不是重新开发一个新系统，而是在原有系统基础上完成接手、复现、分析和升级。

本阶段主要围绕以下方向开展：

- 接手并跑通综合项目 II 已有系统；
- 梳理代码、硬件、数据、接口和 3D 模型；
- 完成会议室数据整理、分析与基础预测；
- 对人脸识别流程进行半自主开发和实质改进；
- 优化 3D 会议室模型、交互和状态联动；
- 提升系统稳定性、可维护性和安全性；
- 完成至少两项功能扩展；
- 完成测试、文档、演示视频和答辩材料。

## 3. 系统总体结构

系统总体采用“感知与硬件层 → 树莓派采集层 → 后端与通信层 → Web/3D 展示层”的结构。

```text
┌──────────────────────────────┐
│          感知与硬件层          │
│ 摄像头 / DHT11 / 光敏 / MQ-2   │
│ PIR / RGB灯 / 舵机 / 其他传感器 │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│          树莓派采集层           │
│ Python采集 / 摄像头 / 传感器读取 │
│ GPIO控制 / 设备控制              │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│         后端与通信层            │
│ Python后端 / WebSocket / API   │
│ 数据处理 / 人脸识别 / 数据存储   │
└──────────┬───────────┬───────┘
           ↓           ↓
┌────────────────┐  ┌────────────────┐
│    Web 前端     │  │    3D 会议室    │
│ 数据展示        │  │ Three.js       │
│ 设备控制        │  │ 状态可视化      │
│ 历史图表        │  │ 场景交互        │
└────────────────┘  └────────────────┘
```

## 4. 综合项目 II 已有功能

### 4.1 树莓派与 IoT

原系统已经完成或测试过以下硬件与功能：

- 树莓派作为主要采集和控制端；
- CSI 摄像头图像采集；
- DHT11 温湿度采集；
- 光敏传感器环境光照检测；
- MQ-2 烟雾传感器检测；
- PIR 人体红外检测；
- RGB LED 状态提示；
- 舵机模拟门禁开关；
- 传感器数据采集与设备控制。

### 4.2 人脸识别与门禁

综合项目 II 已实现基础人脸识别闭环：

```text
摄像头采集
    ↓
Haar 人脸检测
    ↓
图像预处理
    ↓
LBPH 人脸识别
    ↓
身份判断
    ↓
舵机开门 / 门禁联动
```

综合项目 III 将在该基础上进一步完成至少两个关键环节的自主实现或实质改进。

### 4.3 Web 管理平台

已有功能包括：

- 环境数据展示；
- 设备状态显示；
- 设备控制；
- 历史数据/图表展示；
- 摄像头及人脸识别相关功能；
- 会议室状态管理。

### 4.4 3D 会议室

已有 Three.js 会议室场景基础，包括：

- 多会议室场景；
- 会议室设备模型；
- 灯光、门禁等状态展示；
- 场景交互；
- 与系统状态联动的基础能力。

## 9. 已知问题

### 9.1 数据格式尚未完全统一

不同传感器和功能模块的数据字段、时间格式和状态定义需要进一步统一，以便后续数据分析和 3D 状态联动。

### 9.2 3D 状态联动需要复核

已有 Three.js 场景，但部分设备和环境状态是否能够稳定随实时数据变化，需要重新测试。

### 9.3 PIR 人体红外稳定性问题

综合项目 II 测试过程中，PIR 人体红外曾出现持续输出 HIGH 的情况，需要重新排查硬件、GPIO、供电和程序逻辑。

### 9.4 人脸识别自主开发不足

原系统已经可以完成 Haar + LBPH 人脸识别，但综合项目 III 需要进一步自主实现或实质改进关键算法环节。

### 9.5 项目环境和依赖版本记录不完整

原系统部分 Python、OpenCV、前后端依赖和数据库版本尚未统一记录，需要在第 1 周运行基线中重新确认。

### 9.6 系统功能仍有扩展空间

后续可根据实际进度增加多会议室调度、数据分析报告、语音控制或其他会议室智能管理功能。
